# iDash3 v0.8.2-rc5

[English](#english) · [Bahasa Melayu](#bahasa-melayu)

## English

**Prerelease for testing.** iDash3 is a landscape Android launcher with Drive Mode, BitChord, and 10 premium themes using the original wallpapers.

- [Download the signed APK (153 MiB)](https://github.com/shazwannoor95-jpg/iDASH-RELEASED/raw/refs/heads/downloads/v0.8.2-rc5/iDash3-0.8.2-rc5-release-signed.apk)
- [SHA-256 checksum](./iDash3-0.8.2-rc5-release-signed.apk.sha256) · [Source code](https://github.com/shazwannoor95-jpg/iDASH-RELEASED/tree/v0.8.2-rc5)

Requires Android 8.0 (API 26) or later and an ARM32, ARM64, or x86_64 device. Head-unit features depend on the device and its firmware.

This build updates asset credits and privacy information, packages the LGPL notices, and tightens BitChord media controls and Spotify WebView access. Please test playback and media controls on your head unit before relying on this build.

If you installed the debug APK with the same package ID, back up any settings you need and uninstall it before installing this signed build.
