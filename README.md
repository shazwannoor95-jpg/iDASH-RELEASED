# iDash3

Launcher landskap Android dengan Drive Mode, BitChord dan 10 tema yang
menggunakan PNG asal. Minimum Android 8.0 (API 26). ABI binaan lalai ialah
ARM32, ARM64 dan x86_64. Keserasian OEM perlu disahkan pada peranti sasaran.

## Bina release

Gunakan JDK 21, Android SDK platform 37 dan Gradle wrapper yang disertakan.
Jalankan `./gradlew :app:assembleRelease` daripada folder ini.
Hasil release lalai belum ditandatangani.
